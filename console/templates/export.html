How to check this without trusting it

Take the NDJSON export named above. Each line is one envelope in canonical form. For each line: re-derive the envelope identity by hashing the canonical bytes, verify the Ed25519 signature against the key the envelope names, and confirm that the sequence numbers within each stream run without gaps and that each record's prev-hash matches the previous one. A missing record breaks the sequence and the hash chain at the point it was removed. None of that requires this document, and none of it requires software written by the operator of the system.
