Pending approvals

Every action waiting on a named human's signature. Approving here does not create a signature — it records one you made with a key this kernel has never held.

How an answer is produced. Stozher holds no approver private key and has no route that produces an approver's signature, so it cannot manufacture an approval. Sign the request hash with your own owner-only seed file: 
stozher-kernel decide --request <request-hash> --key ~/.stozher/ivan.seed \
                      --subject human:ivan --approve
then paste the object it prints into the form below. The decision travels into the audit as a gate-decision envelope on the kernel's core stream (spec/06 §5) and into the effect that consumes it as authorization (spec/06 §1.3).
